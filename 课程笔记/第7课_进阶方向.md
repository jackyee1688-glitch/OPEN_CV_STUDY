# 第 7 课：进阶方向 —— 深度学习、3D 视觉、智能相机

## 一、深度学习缺陷检测（AI 视觉）

- 传统视觉：人写规则（阈值、轮廓、模板）—— 前面 1-6 课学的都是
- 深度学习：让模型从"大量样本"里自己学"什么是好、什么是坏"
- 三要素：**数据**（成百上千张）、**算力**（显卡）、**框架**（Anomalib / YOLO / Paddle）
- 什么时候用：缺陷形态多变、说不清规则、传统方法调不出来的
- 工作流程：采集数据 → 标注 → 训练 → 验证 → 部署（工业用 GPU 工控机或智能相机）
- 门槛不在"写模型"，而在**数据** —— 所以练习 7 先让你生成数据集，体会"数据是燃料"

## 二、3D 视觉

- 2D：灰度 / 颜色，容易受光照影响
- 3D：每个像素是"高度"，能测高度差、体积、平面度、焊高
- 主流技术：结构光（投影条纹）、双目（两相机三角测距）、激光轮廓仪（线扫）
- 关键概念：深度图（每个像素=高度）、点云
- 什么时候用：高度相关的检测（凹陷、焊高、平面度），2D 做不了

## 三、智能相机 / 一体机

| 方案 | 优点 | 适合 |
|---|---|---|
| 智能相机（海康/基恩士/康耐视） | 相机+处理器+软件一体，免工控机 | 单一稳定应用、现场空间小、快速部署 |
| 工控机 + 工业相机 | 灵活、性能强、可多相机 | 复杂多任务、算法定制 |

## 四、毕业项目（下一步我们一起做）

推荐选题：**垫片尺寸测量 + 缺陷检测 + PLC 分拣**（把 1-6 课全部串起来）
- 背光测直径（标定成毫米）
- 前光查缺陷（阈值余量）
- 模板匹配定位
- TCP 发给 PLC → 放行 / 剔除
- 验收：100 个模拟件，正确率 >= 95%，节拍 < 1s/件

其他选题：药片装盒计数、二维码追溯定位、双相机对位引导
