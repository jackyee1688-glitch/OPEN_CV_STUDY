# 第 2 课：光源与打光 —— 现场视觉成败的第一要素

## 一句话结论

打光决定了图像**对比度**，对比度决定了算法好不好写。现场 80% 的视觉难题，最后都出在打光上。图像拍不好，算法怎么调都没用。

## 光的三个原则

1. **突出要检测的特征，压掉不要的**：检测划痕就让划痕发亮，测量尺寸就让边缘锐利
2. **越稳定越好**：车间自然光、日光灯会变，现场要加光源控制器 + 遮光罩
3. **先打光，后调参**：任何视觉项目第一步是打光试验，不是写代码

## 五种常用光源

| 光源 | 原理 / 长相 | 适合场景 |
|---|---|---|
| 环形光 | 一圈 LED 围在镜头周围 | 通用表面、丝印、字符（最常用） |
| 条形光 | 长条 LED | 大面积表面、反光金属、方向性缺陷 |
| 同轴光 | 分光镜让光线沿镜头光轴 | 反光表面上的字符、刻度、划痕 |
| 背光 | 工件背后发光，拍剪影 | 尺寸测量、轮廓外形检测（测量首选） |
| 穹顶光 | 半球形漫反射 | 球形件、镜面反光件，消除反光 |

## 明场 vs 暗场（核心概念）

- **明场**：光源在工件同侧，反射光直接进相机 → 看到的是"表面信息"（颜色、纹理、字符）
- **暗场**：光源低角度照射，只有凹凸、缺陷处的散射光进相机 → 划痕、压印在暗底上"发亮"
- **背光**：另一种思路，不要表面信息，只要"剪影" → 边缘最锐利 → 测量最准

## 直方图（第 4 课预告）

直方图 = 图像里每种灰度值各有多少个像素。

- 对比度高的图像：直方图是两个**分开的峰**（黑是黑、白是白）→ 阈值分割一次成功
- 对比度低的图像：直方图糊成一团 → 怎么调阈值都切不干净

背光下垫片的直方图就是标准"双峰"，所以阈值分割干净；前光下灰度混在一起，分割全是噪点。
