# 第 5 课：经典视觉应用 —— 开始做"项目"

> 前四课是"零件"，这课开始"组装"。工厂里 90% 的视觉需求就五类：定位、测量、计数、缺陷、读码。

## 一、模板匹配定位（找东西在哪）

- 原理：把"已知的小模板图"在大图里滑动比较，找到最像的位置
- 应用：定位工件坐标 → 引导机械手抓取、对位
- 关键：相似度阈值；局限：对旋转、缩放敏感（进阶用特征点匹配/深度学习）

## 二、几何测量（量多大）

- 原理：第 4 课的轮廓 + 拟合 → 距离 / 直径 / 角度
- 两点距离：欧氏距离；圆直径：最小外接圆/拟合圆
- 应用：装配间隙、孔径、位置度
- 现场注意：先标定（像素→毫米），见第 6 课

## 三、计数与面积（数几个 / 占多少）

- 原理：二值化 → 找轮廓 → 统计轮廓个数 = 数量
- 防粘连：目标太近连成一片时，需要分水岭等进阶算法
- 应用：装盒数量、药片数、元件数

## 四、缺陷检测（好不好）

- 原理：缺陷在图像上 = 异常区域 → 阈值 / 差影法 → 面积超标 = NG
- 差影法：好品图 − 当前图 = 差异区域
- 应用：划痕、脏污、缺料、变形
- 现场经验：缺陷检测最难，打光决定一半成败

## 五、读码与识别（是什么）

- 二维码：OpenCV 自带 QRCodeDetector 直接读
- 条码：需要 zbar / pyzbar 库
- 应用：产品追溯、分拣、防错
- OCR：模板匹配就是最简单的"识别"，工业上用 OCR 引擎或深度学习

## 六、工业软件里的对应（以后你上手 Halcon / VisionMaster 会发现都认识）

| 本课学到的 | Halcon | 海康 VisionMaster |
|---|---|---|

| 几何测量 | caliper / 卡尺 | 几何测量工具 |
| 缺陷检测 | dyn_threshold | 缺陷检测工具 |
