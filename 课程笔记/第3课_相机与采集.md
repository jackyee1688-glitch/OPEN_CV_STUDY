# 第 3 课：相机与采集 —— 从"看"到"拍"

## 一、相机 = 高级传感器（用你熟悉的思维）

- 你熟悉的传感器：把物理量变成电信号
- 工业相机：把"光"变成"数字图像"（像素阵列）
- 关键差异：相机是二维阵列，且每帧能控制的参数更多

## 二、相机五大参数（必须掌握）

| 参数 | 是什么 | 怎么选 |
|---|---|---|
| 分辨率 | 像素数，如 2448×2048 | 精度 = 视野 ÷ 像素数。例：100mm 视野、1000 像素 → 0.1mm/像素 |
| 帧率 FPS | 每秒拍几张 | 由产线节拍定：节拍 0.5s → 至少 2~5fps；运动越快帧率要求越高 |
| 曝光时间 | 快门开多久，决定进光量 | 光线暗→加曝光；运动件→必须短曝光防拖影 |
| 增益 Gain | 电信号放大 | 口诀：先加光→再调曝光→最后才动增益（增益=噪声） |
| 快门方式 | 全局快门 / 卷帘快门 | 运动件必须用全局快门 |

## 三、相机接口（图像怎么传回来）

| 接口 | 特点 | 场景 |
|---|---|---|
| GigE Vision | 千兆网口，线长可达 100m | 工业现场绝对主流 |
| USB3 Vision | 即插即用，速度快 | 小型设备、成本敏感 |
| Camera Link | 极高速，贵，需采集卡 | 高速高分辨率检测 |

## 四、触发模式（什么时候拍照——对应 PLC 的"启动条件"）

- **自由运行**：相机连续不停拍（节拍宽松或调试用）
- **软触发**：软件发一条指令拍一张
- **硬触发**：外部信号（传感器 / PLC）触发拍照 → 现场绝对主流，和你的硬接线习惯完全一致

## 五、曝光与增益的权衡（记住口诀）

先加光 → 再调曝光 → 最后才动增益。
增益是"电子放大器"，放大信号的同时也放大噪声，能不用就不用。

## 六、电脑摄像头 vs 工业相机

- 电脑摄像头：自动曝光、自动白平衡，参数被锁死，便宜
- 工业相机：曝光 / 增益 / 触发全手动可控，稳定可重复——现场要的就是"可重复"
- 练习 3 用电脑摄像头体会"采集"流程，工业相机只是参数更全、控制更硬
