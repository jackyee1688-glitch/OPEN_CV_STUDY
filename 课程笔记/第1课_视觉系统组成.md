# 第 1 课：机器视觉系统由什么组成

## 一、核心类比：视觉系统 = 传感器的升级版

你熟悉的传感器世界：
- 接近开关 / 光电开关 → 输出 0 / 1（数字量）
- 模拟量传感器 → 输出 4-20mA / 0-10V
- 这些信号 → 进入 PLC → PLC 判断 → 驱动执行器

机器视觉世界：
- 相机 + 镜头 + 光源 → 采集图像（相当于"高级传感器"）
- 视觉软件 → 分析图像，输出结果（坐标、尺寸、OK/NG）
- 结果 → 通信给 PLC → PLC 判断 → 驱动执行器

> 结论：你会 PLC，就已经掌握了视觉系统的"后半段"。要学的是"前半段"——如何采到好图像，如何从图像里拿到有用的量。

## 二、视觉系统六大组成

| 组成 | 相当于人体的 | 作用 | 关键参数 / 概念 |
|---|---|---|---|
| 工业相机 | 眼睛 | 光信号 → 数字图像 | 分辨率、帧率、快门、接口 |
| 镜头 | 晶状体 | 决定看得多远多清 | 焦距、视野 FOV、景深、远心镜头 |
| 光源 | 照明 / 化妆 | 决定对比度与稳定性 | 环形、条形、同轴、背光、穹顶 |
| 处理单元 | 大脑 | 运行视觉软件分析图像 | 工控机 + 软件 / 智能相机 |
| I/O 与通信 | 神经 | 与 PLC 交换信号和数据 | 硬触发、TCP/IP、串口、Profinet |
| 算法程序 | 知识经验 | 从图像里提取需要的信息 | 模板匹配、测量、检测、OCR |

## 三、一次完整的视觉检测流程（与 PLC 扫描循环类比）

1. **触发**：传感器或 PLC 给相机触发信号（相当于一个"启动条件"）
2. **采集**：相机曝光，拍下图像
3. **传输**：图像从相机传到处理单元（GigE / USB3）
4. **处理**：软件找特征、算坐标 / 尺寸、判断 OK/NG
5. **输出**：把结果发给 PLC（TCP/IP / 串口 / I/O）
6. **执行**：PLC 根据结果控制气缸、剔除机构、机械手

## 四、必懂术语速记

- 像素：图像的最小单元，一个点
- 分辨率：图像的像素数，如 2448×2048
- 灰度：亮度值，0（黑）~ 255（白）
- ROI：感兴趣区域，只处理指定区域，更快更稳
- 标定：把"像素"换算成"毫米"，现场测量必做
- 触发：决定"什么时候拍照"——位置触发 / 定时 / 连续

## 五、新手必踩的坑：坐标陷阱

OpenCV 画图 / 测量用的坐标是 **(x, y)**（x = 列，y = 行），而 numpy 数组访问是 **[行, 列]**，即 gray[y, x]。顺序写反会拿到错误位置的像素，现场调试时极其常见。

示例：圆心在 cv2.circle(img, (300, 200), ...)，正确读取是 gray[200, 300]，而不是 gray[300, 200]。

## 六、动手练习（练习 1）

1. 安装 Python 3.x
2. 安装 OpenCV：pip install opencv-python
3. 写一个程序：
   - 读取一张图片并显示
   - 转成灰度图
   - 输出图片尺寸和某个点的灰度值
4. 用电脑摄像头实时显示（模拟工业相机的实时采图）
