# 写代码入门 —— 从"读"到"改"到"写"

## 为什么要学写代码

- 运行代码：看懂结果
- 改代码：控制结果 —— 到这一步才算"会用"
- 写代码：创造工具 —— 才算"掌握"

现场实际：应用工程师多用图形化工具（Halcon / VisionMaster），但调参、排查、定制逻辑都离不开"读代码"能力；算法 / 开发工程师必须写代码。代码不是目的，是理解视觉原理最快的路径。

## 读代码的方法：永远找这 4 件事

1. **导入**：`import` 了哪些库（cv2 = 图像处理，numpy = 数值计算）
2. **准备数据**：图像从哪来（生成 / 读文件 / 摄像头）
3. **处理**：调用了哪些函数，参数是什么
4. **输出**：`print` 打印了什么，`imshow` / `imwrite` 显示了什么 / 保存到哪

用这个方法读 `练习5_经典视觉应用.py`：
import → 生成场景图 → cv2.threshold / findContours / moments → print / imwrite

## Python 基础速成（够用版）

| 概念 | 写法 | 说明 |
|---|---|---|
| 变量 | `w = 640` | 给数据起个名字 |
| 函数调用 | `cv2.circle(img, (x, y), r, color, -1)` | 函数名(参数)，括号里是参数 |
| 图像取值 | `img[y, x]` | 先写行 y，再写列 x |
| 列表 | `positions = [(40,40), (110,40)]` | 一组数据，用 for 循环处理 |
| 循环 | `for x, y in positions:` | 对列表每个元素做一次 |
| 条件 | `if area > 80:` | 判断 |
| 打印 | `print(f"数量: {n}")` | 花括号里填变量 |
| 注释 | `# 这是一行注释` | 给"人"看的说明，不影响运行 |

## 改代码的通用套路

1. 右键 `.py` 文件 → 打开方式 → **记事本**（或 VS Code）
2. 用 Ctrl+F 找到要改的位置
3. **只改你想改的地方**，其他不要动
4. 保存（Ctrl+S）
5. 重新运行，看结果变了没有

## 第一个改代码任务（练习5 的计数演示）

打开 `练习5_经典视觉应用.py`，找到"应用3"里的这行：

positions = [(40, 40), (110, 40), (180, 40), (250, 40), (70, 110), (140, 110), (210, 110), (45, 180), (115, 180), (185, 180)]
