# 第 6 课：视觉 + PLC 集成 —— 把视觉接进你的系统

## 一、为什么这一课对你最重要

现场视觉不是独立的：相机拍照 → 视觉算结果 → **结果要交给 PLC** → PLC 控制执行机构。
你懂 PLC，这一课就是把"你熟悉的世界"和"视觉"连起来。

## 二、通信方式总览

| 方式 | 特点 | 典型场景 |
|---|---|---|
| TCP/IP（以太网） | 通用、快、线长、数据量大 | 主流，结果 / 坐标 / 图像都能传 |
| 串口 RS232 / 485 | 简单、慢、抗干扰好 | 老设备、短报文 |
| Modbus TCP | 工控标准协议 | 很多 PLC 原生支持 |
| Profinet / Ethernet/IP | 工业实时以太网 | 西门子 / 罗克韦尔等 |
| 硬接线 I/O | 一个结果一根线（0/1） | 只需要 OK/NG 的简单场合 |

绝大多数视觉项目用 TCP/IP：视觉系统做服务端或客户端，与 PLC 通过协议收发数据。

## 三、TCP/IP 通信的思维（拿你熟悉的打比方）

- 视觉端 = 一个"带 IP 地址的设备"，像一台从站
- 端口号 = 设备上的"服务窗口"
- 流程 = 建立连接（握手）→ 发数据（拍照请求 / 结果）→ 断开
- 数据格式 = 双方约定好的文本或字节（如 "OK\n"、"NG\n"，或 "X坐标,Y坐标,角度"）

## 四、像素 → 毫米（标定）

- 相机看到的是像素，产线要的是毫米
- 标定方法：放一个已知尺寸的标准件（比如直径 9mm 的垫片），量它在图像里占多少像素
- 精度 = 真实尺寸 ÷ 像素数 = 9mm ÷ 180px = **0.05 mm/像素**
- 之后任何测量：像素数 × 0.05 = 毫米
- 现场还有畸变校正、手眼标定等高级标定，原理都是"像素与真实世界的换算关系"

## 五、练习 6 的完整流程

两个窗口两个程序（本课用模拟 PLC，道理和真 PLC 一样）：

1. 窗口1：模拟 PLC 端启动，监听 TCP 端口
2. 窗口2：视觉端启动，连接 PLC
3. 视觉端逐个检测 5 个工件（含坏品）
4. 每个结果通过 TCP 发给 PLC："OK" 或 "NG"
5. PLC 端收到后"动作"：放行 / 气缸剔除，并累计统计

## 六、真实项目的样子

1. 传感器检测到工件到位 → 硬触发相机拍照
2. 视觉算结果（OK/NG、坐标、尺寸）
3. TCP/IP 发给 PLC
4. PLC 执行：放行 / 剔除 / 告诉机械手抓取
5. 全程节拍满足产线速度
