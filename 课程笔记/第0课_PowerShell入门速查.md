# 第 0 课：PowerShell 入门速查表（够用版）

> 目标：会打开终端、会切目录、会运行 python 脚本，就够了。
> 后面的课程全部用这几个命令。

## 一、PowerShell 是什么

终端 = 用"文字命令"操作电脑的窗口。PowerShell 是 Windows 自带的一款终端。

电气工程师类比：就像你用组态软件、或者电脑的"命令提示符"黑窗口，只是 PowerShell 功能更强。

## 二、怎么打开

- 方法 1：按 Win 键 → 输入 `powershell` → 回车
- 方法 2（推荐）：打开目标文件夹（比如"视觉"文件夹）→ 在窗口顶部**地址栏**里输入 `powershell` → 回车
  → 打开的终端会直接定位在这个文件夹，省去切目录

## 三、五个最常用命令

| 想做什么 | 敲什么 | 说明 |
|---|---|---|
| 看当前在哪个目录 | `pwd` | 显示当前位置（绝对路径） |
| 列出文件夹内容 | `ls` | 显示当前目录下的文件和文件夹 |
| 进入某个文件夹 | `cd 文件夹名` | 切换目录 |
| 返回上级目录 | `cd ..` | 两个点 = 上一级 |
| 清屏 | `cls` | 清掉屏幕上旧内容 |

## 四、三个救命技巧

1. **Tab 自动补全**：敲 `cd ` 或 `python ` 后，按 Tab 键自动补全名字，输入 练习 再按 Tab 就会变成完整文件名
2. **上箭头 ↑**：调出上一条命令，改改再回车，不用重敲
3. **Ctrl + C**：程序卡住或不想要了，按这个强制停止

## 六、常见报错排查

| 报错提示 | 原因 | 解决办法 |
|---|---|---|
| 无法将"python"识别为... | 这个窗口在装 Python 前就开了 | 关掉重开一个新窗口 |
| 找不到文件 / 路径不存在 | 当前目录不对 | 先 `pwd` 看位置，再 `cd C:\Users\FCW\Desktop\视觉` |
| 程序一直不结束 | 窗口在等你按键 | 到终端按任意键，或 Ctrl+C |
