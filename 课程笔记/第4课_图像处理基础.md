# 第 4 课：图像处理基础 —— 从"图像"到"信息"

## 一、处理流水线（对应你的 PLC 程序思维）

原图 → 预处理（滤波）→ 分割（二值化）→ 分析（轮廓 / 特征）→ 结果输出

| 图像处理环节 | PLC 里的对应物 |
|---|---|
| 滤波 | 模拟量滤波，去掉信号抖动毛刺 |
| 二值化（阈值） | 比较器：设定值上/下 |
| 轮廓 / 特征计算 | 计算指令（面积、中心、直径） |
| 结果输出 | 数据块发给上位机/触摸屏 |

## 二、灰度与直方图

- 灰度：0（黑）~ 255（白）
- 直方图：图像里每种灰度值各有多少个像素
- **双峰** = 黑白分明 = 阈值好切
- **单峰 / 糊在一起** = 对比度差 = 打光或预处理有问题

## 三、二值化（阈值分割）

- `threshold`：像素 > 阈值 → 白(255)，≤ 阈值 → 黑(0)
- 作用：把"目标"从"背景"里切出来
- 第 2 课背光图一次切成功，就是因为它直方图是双峰

## 四、滤波去噪

| 滤波 | 作用 | 典型场景 |
|---|---|---|
| 均值 blur | 平滑，去随机噪声 | 一般去噪 |
| 高斯 GaussianBlur | 平滑更自然 | 常用 |
| 中值 medianBlur | 去椒盐噪声 / 斑点 | 焊点、麻点表面（推荐） |

## 五、形态学（二值图整形）

- 膨胀：白色区域变大 → 填小孔
- 腐蚀：白色区域变小 → 去小点
- 开运算 = 先腐蚀后膨胀 → **去孤立噪点**（最常用）
- 闭运算 = 先膨胀后腐蚀 → 填内部小孔
- 现场经验：二值化后先用开运算"扫一遍垃圾"，再提取特征

## 六、边缘检测（Canny）

- 找灰度突变的位置 = 边缘
- 适合：定位参考、轮廓提取

## 七、轮廓与特征（测量的雏形）

- 轮廓 = 二值图中白色区域的边界
- 常用特征：面积、周长、质心（中心）、最小外接圆
- 例子：背光垫片 → 二值化 → 找最大轮廓 → 拟合圆 → 直径 ≈ 180 像素
- 第 6 课加上"标定"，把像素换算成毫米，就是正式的尺寸测量
